# Medical-center and clinic map references

The shared map and private nearest-facility calculation use one catalogue: 966 named Zimbabwe and 39 named Eswatini hospital/clinic OSM records, from the HOT national extracts dated 2026-10-07. These are mapped records, not an exhaustive official registry or verified operational facilities. Distinct OSM objects may describe the same site; no fuzzy merge is performed.

Source: [Humanitarian OpenStreetMap national extracts](https://data.humdata.org/dataset/hotosm_zwe_health_facilities), [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL 1.0. The derived JSON dataset is distributed under ODbL 1.0 separately from the code license. Each entry retains OSM identity, archive URL, snapshot, SHA-256 and coordinate method. Country assignment uses the source ADM0 boundary code. Named hospital/clinic tags are included; pharmacies, unnamed sites and unrelated healthcare categories are omitted.

`python scripts/build-medical-center-catalogue.py SOURCE_DIRECTORY` reproduces the catalogue from `ZWE.zip` and `SWZ.zip`. `--download` explicitly refreshes those public HOT archives. The script validates archive size, license, country, geometry, coordinates and duplicate identifiers. It reads ZIP entries without extracting paths. Sources for this review remain under `.codex/medical-center-sources/`. Refreshes may change hashes and coverage; inspect the output before committing.

Points retain their mapped position; polygons use their bounds centre, not an entrance. The Gateway embeds the same JSON used by the map. Authorized report reads calculate Haversine straight-line kilometres from occurrence coordinates only, selecting clinic and hospital independently within the occurrence country. Neither private coordinates nor route origins appear in DTOs or external map links. Approximate locations and reported accuracy remain explicit. When report coordinates are unavailable, the approved fallback uses a single matching settlement from the existing geographic registry, constrained by country and region. It explicitly labels distances as estimates from that locality centre, never the exact report location. Ambiguous matches, country/region centroids and missing places have no estimate. The nearest result means nearest in this incomplete catalogue, not referral advice or confirmed service availability. No external routing call is made.

Facility layers never contribute to case counts or surveillance suppression. Legend toggles are independent. No database migration, runtime directory request, API key or dependency is introduced.
