## Segmented audio frame bounds - 3 November 2026

`EllaiSpeechEvent.Validate` previously checked `SamplePosition + pcmSamples > MaximumPosition`. With unchecked `long` arithmetic, a malicious `long.MaxValue` position plus an audio sample could wrap negative and pass validation. The check now compares `SamplePosition > MaximumPosition - pcmSamples`, rejecting overflow before encoding or gateway decoding.

- PASS - focused `EllaiSpeechEventContractTests` 4/4, including last-valid-sample, position-at-limit, `long.MaxValue` encode and malformed decode.

## EV-093 - explicit action-owner transfer - 3 November 2026

`ActionOwnerChanged` now makes action transfer explicit and replayable. Its required `actionKind` (`FollowUp` or `Assistance`) disambiguates separate action ID spaces; the event records the action ID, previous owner, new owner, actor, aggregate/report versions, timestamps and reason. Only open actions can be transferred, the new owner must differ from the current owner, and the command requires the matching `ManageFollowUp` or `ManageAssistance` capability.

The application processor locks the proposed new owner and validates current eligibility under the corresponding follow-up or case-assignment policy. The Gateway API accepts `ChangeActionOwner`; canonical command hashing binds action kind, ID, new owner and reason. PostgreSQL writes the event and updates the associated follow-up or assistance projection within the command transaction; the strict journal reader validates and replays the event. Case timeline labels identify the transfer without exposing payload details.
