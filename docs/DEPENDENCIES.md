# Dependency and compatibility record

Source of truth for the intended stack and task graph: implementation.md v2.4 §§3–5, 19, 21. This file records observations, not a validated bill of materials.

## Intended architecture

Android-first .NET MAUI Blazor Hybrid client with native SQLite/Datasync offline read models and drafts; MudBlazor primary UI and conditional Syncfusion specialized controls; ASP.NET Core gateway and web surfaces; PostgreSQL/PostGIS authoritative persistence; MinIO private originals storage; Redis backend cache/exact-result cache; private Qdrant scoped AI memory/search index; NATS JetStream; optional FCM push; Python workers; Microsoft AI/MCP integration with Meta-only permitted inference. Qdrant, Redis and object storage do not replace PostgreSQL authority. Owner-approved service configuration and current source/runtime distinctions are documented in [SERVICES.md](SERVICES.md). The plan §3.3 says Redis is not required; the owner's separate Redis choice is recorded in [SPEC-ALIGNMENT.md](SPEC-ALIGNMENT.md) without rewriting the plan.
