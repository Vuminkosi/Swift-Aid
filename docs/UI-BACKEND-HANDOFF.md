This document identifies existing backend contracts and capability gaps for frontend integration. It does not create backend requirements beyond the approved product/implementation contracts, nor assert provider or deployment readiness.

## Missing or incomplete backend capabilities

The current source does include authorized case queue, summary, monitoring, dashboard/analytics read, privacy-scoped map aggregate, and command-backed follow-up/escalation seams. Their registrations do not establish that every deployment has the required query/command services enabled or that the full UI journey has passed. Remaining gaps include organization administration/membership, general case assignment/reassignment, cross-case assistance, public subscriptions/attendance, approved education catalog/download APIs, analytics export, and live AI investigation. Typed frontend organization, investigation and work-management contracts are not automatically approved wire APIs. The shared work-management client supports only explicit command mappings and carries expected versions; it remains fail-closed for unsupported operations. Organization and investigation mutation contracts still need approved wire semantics. Before adding or extending live adapters, approve request/response, authorization, pagination/filter, concurrency/idempotency, error/retry, and capability/version semantics for the specific missing operation.

`GuestReport` injects `IAudioCaptureService`, `IAudioPlaybackService` and `IGuestAudioStore`. Android registers `AndroidAudioCaptureService` for capture/playback; non-Android targets register an unsupported adapter. Guest audio is encrypted in local app storage. No guest-media upload endpoint exists, so original audio remains local-only and its local ID must never be sent as a server attachment. Permission prompts, device capture/playback and provider transcription are NOT VERIFIED. AI investigation remains administrative case continuity only; generated clinical guidance is prohibited.

## PC-09 routing restrictions

Per `docs/SPEC-ALIGNMENT.md` §PC-09, coordinator reads are minimum necessary: receipt identity, lifecycle/queue state, coarse area codes, subject scope and timing. Exclude narrative, observations, precise coordinates and original audio. Decisions are versioned and reasoned; clarification is factual and cannot invent reporter contact details. Routing targets only eligible configured organization queues. Coordinators cannot impersonate users, create grants, self-assign or promote; only the organization reviewer may accept. Geography alone does not grant access.
