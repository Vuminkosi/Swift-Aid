# SwiftAid reuse and implementation matrix - 2 November 2026

## How to read this matrix

- **REUSE**: a canonical implementation path already exists; keep using it.
- **EXTEND**: the existing path is the correct home, but checklist behavior or acceptance is incomplete.
- **NEW**: source search found no canonical handler/store for the capability; add it only within the existing architecture and contracts.
- **BLOCKED**: code can remain in place, but its capability must stay disabled or unclaimed until the stated provider, rights, authority, or runtime gate is met.

These classifications describe source structure and mapped tests. They do not mark product requirements Passed. Current suite totals and observed failures are in `ACCEPTANCE.md` and `BASELINE-AUDIT.md`.
